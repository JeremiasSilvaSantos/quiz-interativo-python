# Sistema de Quiz Interativo em Python 🧠

Repositório contendo um jogo de perguntas e respostas via terminal desenvolvido em Python puro, sem dependência de bibliotecas externas, com sistema de ranking e validação robusta de entradas.

## Autor
* **Jeremias Silva Santos**

## Funcionalidades
1. **Quiz de Geografia**: Perguntas sobre capitais, oceanos, desertos e rios.
2. **Quiz de História do Python**: Questões sobre a criação, origem do nome e filosofia da linguagem.
3. **Quiz de Biologia**: Conceitos de citologia, fotossíntese e genética básica.
4. **Quiz de Matemática**: Desafios rápidos de aritmética, geometria e constantes.
5. **Quiz Geral (Misto)**: Reúne todas as categorias em uma única rodada completa.
6. **Ranking Ordenado**: Classificação automática dos jogadores da maior para a menor pontuação, exibindo a categoria jogada.
7. **Blindagem de Entradas**: Tratamento contra alternativas inválidas, espaços extras, letras minúsculas e nomes em branco.

## Como Executar

Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.

1. Baixe e extraia os arquivos do projeto.
2. Abra o terminal na pasta `quiz-python-interativo`.
3. Execute o comando:
   ```bash
   python quiz_system.py
   ```
